# Project Development Rules

## Rule 1
Always use controlled React components for every form input.

## Rule 2
Every required input must include proper validation, descriptive error messages, and accessibility attributes (`aria-invalid`, `aria-describedby`).

## Rule 3
Every new feature must include automated tests using React Testing Library and Vitest before merging.

## Rule 4
Keep presentation styles in CSS files instead of inline styles whenever possible.

## Rule 5
Review AI-generated code for accessibility, validation, and edge cases before accepting it.
