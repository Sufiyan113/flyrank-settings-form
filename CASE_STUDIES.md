# Case Study – FlyRank AI-Assisted Settings Form

## Problem

I needed to build a React Settings Form that demonstrated AI-assisted software development. The assignment required comparing a vague AI prompt with a precise AI prompt while implementing validation, testing, and documentation.

## What I Did

I built the settings form using React and CSS. I implemented client-side validation, wrote automated tests using React Testing Library, documented the AI workflow in WORKFLOW.md, created project rules in CLAUDE.md, and managed the project using separate Git branches before merging the final version into the master branch.

## What Came Of It

The project improved my understanding of AI-assisted development, Git branching, testing, accessibility, and documentation. It also showed that detailed prompts reduce review effort and produce better-quality code.
